# Home Automation System

## Components

- PIC16F877A
- Light
- Fan
- Temperature Sensor
- Green LED
- Red LED
- Buzzer
- LCD
- UART Virtual Terminal

## Function

The system controls the light and fan and displays the system status on the LCD.

- Light → ON/OFF control
- Fan → ON/OFF control
- Temperature → Temperature information
- Green LED → Normal status
- Red LED + Buzzer → Alert status
- UART → Displays system information
